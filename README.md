# Система мышления для Claude Code

Набор правил, который меняет не знания модели, а **способ её работы**: как понять задачу с первого раза, как принимать решения, как проверять себя и результат, как не останавливаться на полпути и как учиться на своих ошибках.

## Из чего состоит

| Слой | Что делает | Где |
|---|---|---|
| Понимание задачи | Первым блоком — «Как я понял задачу»: чистый текст просьбы, цель, объект, объём. Сигналы в словах пользователя («опять», «тормозит», «найди сам») | `CLAUDE.md` §1–3, хук `task-framing.sh` |
| Автономность | Делать самому без вопросов «окей?»; останавливаться только на необратимом, чужом и деньгах — блоком «Ждёт вашего да» в конце | `CLAUDE.md` §2 |
| Решения | Воронка: флаги риска → уровень L0–L4 → варианты по механизмам → сборка лучшего → самопроверка допущений и контрпримеров → kill-критерии | `~/.claude/docs/decision-funnel.md` |
| Поиск готового | Сначала найти лучшее существующее, потом делать своё | навык `find-first` |
| Проверка | Доказательство — конечный результат, а не код возврата; один независимый проверяющий, до 3 кругов; блок «Поправки» | `~/.claude/docs/verification.md`, помощники `verifier`, `critic` |
| Роль и фильтр | Слой вопроса, чьё решение, рамка; цифры со знаменателем; линзы мышления | `.claude/workspace/SOUL.md`, `PROTOCOLS.md` |
| Безопасность | Разрушительные команды блокируются до явного «да» | хук `destructive-bash-guard.sh` |
| Обучение | Повторная поправка сразу уходит в правило или хук; урок из каждой ошибки | `CLAUDE.md` §8, словарь `WORDS.md` |
| Долгие процессы | Работа не обрывается с концом ответа: `systemd-run --user` с логом, запрет отцепленных запусков, `nice` для тяжёлого, раннер пачек, оповещение в конце | `CLAUDE.md` §10, хуки `detached-launch-guard.sh`, `heavy-task-nice-guard.sh`, `longproc-*`, `scripts/runjob.sh`, `scripts/notify.sh` |
| Здоровье сервера | Лимиты служб, сторож нагрузки/диска/циклящихся служб | `CLAUDE.md` §11, `scripts/watchdog.sh`, навык `health` |
| Память дела | Страница темы между чатами, хвосты проверок прошлого чата, уроки из ошибок | `CLAUDE.md` §12, `scripts/topics/`, `scripts/verify/`, `.claude/learning-loop/`, хуки `topic-prompt.py`, `verify-*.sh`, `loop-*.sh` |
| Документы людям | Word/Excel, страницы смотреть глазами до отправки | `CLAUDE.md` §13, `scripts/docxkit/`, навыки `docx`, `xlsx` |
| Помощники | Критики по областям (процессы ИИ, сервер, фронтенд), проверяющий, аналитик, архитектор, планировщик, трассировщик, отладчик, исследователь, исполнитель, ревьюеры кода и безопасности, тестировщики, писатель, дизайнер | `.claude/agents/` |
| Навыки | Поиск готового, промпты, глубокое интервью, создание навыков, тест веб-приложений, здоровье сервера, кривая стоимости LLM | `.claude/skills/` |
| Самопроверка | Каждый хук получает тестовый вход и должен ответить как задумано | `scripts/thinking-selftest.sh` |

## Как поставить

Проще всего отдать ссылку своему Claude Code:

> Установи систему мышления из https://github.com/Seikatsuma/claude-thinking-system — прочитай INSTALL-FOR-AI.md и сделай по нему.

Руками: сохранить свои `~/CLAUDE.md` и `~/.claude/`, скопировать `.claude/*` в `~/.claude/`, `scripts/` в `~/scripts/`, дописать `CLAUDE.md` к своему, влить хуки из `.claude/settings.json` в свой, прогнать `bash ~/scripts/thinking-selftest.sh`.
