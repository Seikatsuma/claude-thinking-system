# Установка системы мышления (инструкция для ИИ-агента)

Ты — Claude Code на машине пользователя. Поставь набор так, чтобы у пользователя ничего не потерялось.

1. Склонируй репозиторий во временный каталог.
2. Сделай резервную копию: `~/CLAUDE.md`, `~/.claude/settings.json`, `~/.claude/hooks`, `~/.claude/agents`, `~/.claude/skills`, `~/.claude/workspace` → `~/claude-backup-<дата>/`.
3. Скопируй файлы в `~` с сохранением путей. Если у пользователя уже есть файл с тем же именем — не затирай молча: покажи различия и объедини, правила пользователя важнее.
4. `settings.json`: не заменяй файл целиком. Для каждого события из раздела `hooks` (`UserPromptSubmit`, `PreToolUse`) допиши элемент в конец существующего массива этого события; если события нет — создай массив. Чужие хуки пользователя не удаляй. Проверь, что файл остался валидным JSON.
5. `chmod +x ~/.claude/hooks/*.sh`. Нужны `bash` и `python3`.
6. Заполни `~/.claude/workspace/USER.md`, расспросив пользователя (кто он, как объяснять, что можно без вопросов).
7. Проверка: в новой сессии на содержательное сообщение должен прийти «ПРОТОКОЛ ИСПОЛНЕНИЯ» от `task-framing.sh`; команда `rm -rf ~/проверка-удаления` должна блокироваться `destructive-bash-guard.sh`.
8. Коротко отчитайся пользователю: что установлено, где резервная копия, что объединено вручную.
