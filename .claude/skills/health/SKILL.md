# health — состояние сервера

Один экран о жизни сервера. Та же сводка, что приходит по `/health` в телеграме, —
чтобы не приходилось помнить, где спрашивать.

## Что сделать

Запусти и покажи результат пользователю как есть, без пересказа:

```bash
python3 ~/scripts/guardian.py --health --plain
```

Вывод уже написан человеческим языком и не требует перевода. Не добавляй к нему
таблиц и не расшифровывай метрики, если пользователь не спросил.

## Как читать ответ

- **🟢 всё спокойно** — вмешательства не нужно.
- **🟡 прибираюсь** — завхоз чистит своё, пользователя это не касается.
- **🟠 работаю над этим** — что-то происходит: цикл рестартов, упавший сервис или
  нехватка места. В выводе будет сказано, что именно.
- **🔴 нужен ты** — дальше только решения пользователя; предложения ждут в `/yes`.

Строка **«Последняя проверка: N мин назад»** — сторож сторожа. Больше 20 минут
означает, что расписание сломалось: проверь `crontab -l` и
`~/.claude/guardian/cron.log`.

## Если попросят прибраться прямо сейчас

```bash
python3 ~/scripts/guardian.py --report
```

Убирает только своё (кэши, временные файлы, брошенные процессы). Боты, документы и
чаты пользователя не трогает — на них нужно его слово, оно даётся командой `/yes` в
телеграме.

Устройство сторожей и их границы — `~/scripts/agent.md`.
